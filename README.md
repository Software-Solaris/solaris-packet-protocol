# Solaris Packet Protocol (SPP)

SPP is a small, portable C11 library for packaging and routing sensor data as structured packets on embedded systems, used by [Solaris Software](https://github.com/Software-Solaris/solaris-software).

Full documentation — architecture, design, API reference — lives on the website:

**[softwaresolaris.com](https://softwaresolaris.com)**
